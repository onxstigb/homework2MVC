# Homework 2 - MVC Magic: The Gathering Website

## Project Description

This project is a simple Magic: The Gathering themed website created for Homework 2.

The website demonstrates the **Model-View-Controller (MVC)** concept by using JavaScript to change the content displayed on the page when a navigation link is clicked.

The website includes four sections:

* Home
* Formats
* Cards
* About

Each section contains unique text and an image.

## Technologies Used

* HTML
* JavaScript
* SCSS
* npm
* GitHub

## MVC Structure

The project uses two JavaScript files:

### Model - `model.js`

The Model contains the information for each page, including the HTML, text, and images. The `changePage()` function selects the requested page and displays it inside the `#app` element.

### App - `app.js`

The App handles the navigation links and detects which page the user selects. It then sends the selected page name to the Model.

## Project Features

* Four working navigation links
* Unique content for each page
* Images on every page
* Dynamic page changes without refreshing the website
* Data provided through the Model
* SCSS styling
* npm project setup with `package.json`
